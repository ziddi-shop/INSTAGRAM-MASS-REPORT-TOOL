## 📌 About The Project

**Instagram Mass Report Tool** is a Python-based command-line project developed under the **ZIDDI** name. It includes Instagram authentication, session handling, target username lookup, and reporting workflows through a terminal interface.

The project supports account login, session-based authentication, challenge handling, and single-account or multi-account operation modes.

---

## ✨ Features

- 🔐 Password-gated tool access
- 👤 Instagram account login
- 🔑 Session ID authentication
- 🛡️ Two-factor authentication and challenge handling
- 💾 Session persistence
- 🎯 Target username lookup
- ⚙️ Single-account and multi-account modes
- 📊 Request status and result display
- 🧵 Concurrent task processing
- 🖥️ Terminal-based interface
- 🔒 PyArmor code protection for compatible builds
- 📱 Windows, Linux, and Termux setup guidance

*Feature availability depends on the included build, dependencies, and platform compatibility.*

## 🚀 Installation

### 🪟 Windows

**Step 1 — Install Python**

Download Python from [python.org](https://www.python.org/downloads/).

During installation, enable **Add Python to PATH**.

**Step 2 — Clone the repository**

```bash
git clone https://github.com/ziddi-shop/INSTAGRAM-MASS-REPORT-TOOL.git
cd INSTAGRAM-MASS-REPORT-TOOL
```

**Step 3 — Install the dependency**

```bash
py -m pip install --upgrade pip
py -m pip install instagrapi
```

**Step 4 — Start the tool**

```bash
py main.py
```

Ensure all required project files and the matching PyArmor runtime are present.

### 📱 Android — Termux

**Step 1 — Install the required packages**

```bash
pkg update
pkg install python git -y
```

**Step 2 — Clone the repository**

```bash
git clone https://github.com/ziddi-shop/INSTAGRAM-MASS-REPORT-TOOL.git
cd INSTAGRAM-MASS-REPORT-TOOL
```

**Step 3 — Install the dependency**

```bash
python -m pip install --upgrade pip
python -m pip install instagrapi
```

**Step 4 — Start the tool**

```bash
python main.py
```

**Important:** A PyArmor runtime built for Windows will not automatically work on Android. Termux requires a compatible runtime and build for its platform. Copying Windows runtime files to Termux is not sufficient.

### 🐧 Linux — Ubuntu/Debian

**Step 1 — Install Python and Git**

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv git
```

**Step 2 — Clone the repository**

```bash
git clone https://github.com/ziddi-shop/INSTAGRAM-MASS-REPORT-TOOL.git
cd INSTAGRAM-MASS-REPORT-TOOL
```

**Step 3 — Create a virtual environment**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Step 4 — Install the dependency**

```bash
python -m pip install --upgrade pip
python -m pip install instagrapi
```

**Step 5 — Start the tool**

```bash
python main.py
```

## 🔒 Code Protection

The project may use **PyArmor** to protect Python source code before distribution.

- Keep required runtime files alongside the protected build.
- Build separately for platforms that require different runtimes.
- Test the protected build before publishing.
- PyArmor makes source inspection harder but cannot guarantee complete protection against reverse engineering.
